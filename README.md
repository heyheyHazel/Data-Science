## 🚀 快速开始

### 环境配置

```bash
# 克隆仓库
git clone https://github.com/heyheyHazel/Data-Science.git
cd Data-Science

# 创建虚拟环境并安装基础的包(conda)
conda create -n pytorch_env python=3.9 -y
conda activate pytorch_env
conda install pytorch pandas numpy matplotlib ipykernel  -y
